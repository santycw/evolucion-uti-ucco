# Parche nomogramas de dilución para calculadora de infusiones

Agrega sugerencias de dilución según el PDF `NOMOGRAMAS ACTUALIZADOS.pdf`:
- Fentanilo, remifentanilo, morfina, ketamina, midazolam, propofol, dexmedetomidina, lorazepam, clonidina.
- Atracurio, vecuronio, pancuronio y rocuronio.
- Se agregan presentaciones que faltaban: propofol 2%, lorazepam, clonidina, vecuronio y rocuronio.
- La UI permite seleccionar una dilución sugerida y aplicarla automáticamente a `Cantidad Ampollas` y `Volumen final / Dilución`.
